# OFPPT Portfolio

Personal portfolio featuring web development projects and practical coursework.

## Projects

The website groups completed projects and ongoing work. Edit `script.js` to add projects or update their status. Each project can include a repository or live-demo link.

## Built with

HTML, CSS, JavaScript, Bootstrap, React, Vite, PHP, Laravel, MySQL, Python, and SQL.

## Run locally

Open `index.html` in a browser.
